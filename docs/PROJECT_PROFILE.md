## 判定ガイド

次のいずれかがあればStandard以上とする。

- 複数チームまたは外部組織が利用する。
- 個人情報、機密情報、決済、認証を扱う。
- 本番停止が業務へ影響する。
- 外部API、クラウド、オンプレ、エッジ、ハードウェアと連携する。
- データ移行や後方互換性が必要。

医療、金融、法規制、重要インフラ、安全性に関係する制御、監査義務があればRegulatedを検討する。
